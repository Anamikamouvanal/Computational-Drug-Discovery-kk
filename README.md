# Network Pharmacology and Computational Drug Discovery Analysis of Kabasura Kudineer Against Cancer Metabolism
## Overview
This Research project investigates the anticancer potential of bioactive phytoconstituents present in Kabasura Kudineer using an integrated computational drug discovery workflow. The study combines network pharmacology, molecular docking, ADMET prediction, and molecular dynamics simulation to identify potential therapeutic compounds and molecular targets associated with cancer metabolism.

## Project Objective
To identify bioactive compounds from Kabasura Kudineer with potential anticancer activity against cancer metabolism using an integrated network pharmacology and computational drug discovery approach.

## Workflow
1. Phytochemical collection and screening
2. Molecular target prediction
3. Protein–protein interaction analysis
4. GO and KEGG enrichment analysis
5. Molecular docking
6. ADMET evaluation
7. Molecular dynamics simulation
8. Interpretation of anticancer mechanisms
## Tools Used
- AutoDock Vina
- PyRx
- GROMACS
- Cytoscape
- STRING
- SwissADME
- Enrichr
- Metascape
## Key Findings
- Identified multiple bioactive phytoconstituents with favorable drug-likeness properties.
- Predicted interactions with cancer metabolism-related targets.
- Enrichment analysis highlighted pathways associated with glucose metabolism, hypoxia, and cancer progression.
- Selected compounds demonstrated promising binding affinity toward key therapeutic targets.
